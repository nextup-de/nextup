Buttons that share a row inside a card - "Co-sign this idea" / "Ask a question".
```jsx
<div style={{display:"flex",gap:8}}>
  <Btn kind="primary">Co-sign this idea</Btn>
  <Btn>Ask a question</Btn>
</div>
```
- 44px rows, 8px corners. Default is grey fill #f2f2f7; primary is ink #1c1c1e; muted is grey with mute text; disabled is 45% opacity.
