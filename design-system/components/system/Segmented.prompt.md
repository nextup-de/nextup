Switches between views of the same thing.
```jsx
<Segmented value="idea" items={[{label:"Idea",key:"idea"},{label:"AI",key:"ai",icon:<Icon name="plus" size={10} width={2.6} />}]} />
<Segmented tone="white" value="open" items={[{label:"Open",key:"open",count:4},{label:"Archive",key:"archive",count:2}]} />
```
