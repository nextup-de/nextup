Draws any NextUp icon from the product's own path set - 24×24 viewBox, round caps, 1.9 stroke.
```jsx
<Icon name="idea" size={16} />
<Icon name="up" size={11.25} color="#fff" width={2.6} />
<Icon name="sparkle" size={9} solid />
```
- Small icons get heavier strokes (x at 7.5px uses width 3). Solid only for bolt (actions) and sparkle (AI).
- Never mix in another icon library; there is no icon font.
