## What

- Add a section **above** `<!-- BEGIN:turborepo-agent-rules -->` (never inside the markers) with:

  - the folder rules (`src/app` thin routes, `components` render only, `features` decide with no React,
    mutations through `src/server/actions/`), roles are data (`canAccess()`), the tenant is the `[company]` segment,
    events not edits;

    sandbox;
  - done = `npm run lint && npm run typecheck && npm test && npm run build` green;
  - git rules: never commit to `main`, never force-push, never `git add -f`, never touch `.gitignore`, `.github/`,
    `package.json`, `package-lock.json`, `.env*`; no AI attribution;
  - the "stop and ask" list from CLAUDE.md (new dependency, config change, new event type, schema change, new role,
    auth change, secrets);

    paths; do not run `git commit` (the runner commits); no network, no installs; do not run DB, Docker or e2e
    commands; finish with the JSON report that matches
