## Setup as found and as changed

- **Relay:** `SMTP_URL` was already set to Brevo (`smtp-relay.brevo.com:587`, set 2026-11-07 23:25), with
  `MAIL_FROM="NextUp <nextup@sellux.ch>"`. The running app had it. SMTP AUTH from inside the app container answered
  `235 Authentication succeeded`; no mail was sent by that check. sellux.ch has `include:spf.brevo.com` in SPF, Brevo DKIM
  CNAMEs (`brevo1/brevo2._domainkey`) and DMARC `p=none`. Kevin chose to keep Brevo. Not chosen: a tenant mailbox with SMTP

## Findings

1. **Mail lands in Junk** in Exchange Online, although SPF, DKIM and DMARC are set up for the sending domain. Possible
   causes: a new mailbox, a first-time sender, plain text with bare links. Fix options: a tenant allow entry or transport
   rule for `sellux.ch`, or "Not junk" per mailbox; for a customer, a sender domain of their own or their own relay.
   Headers not inspected.
2. **The description appears twice** in the case notice (once as the idea text, then the added detail again), and **the
   case link twice** (in the text and appended by the mail channel, `server/notify/channels/mail.ts`: `text + "\n\n" + link`).
3. **Mail language falls back to English** for everyone without a profile language: `CompanyConfig.defaultLocale` is empty
   on Musterwerk, and only Julia has `locale = de` (524 of 525 people have none). The weekly report to Kevin and all 61
   reminders of 7 Nov are English. The Entra `preferredLanguage` (de for Kevin) is not read. Fix for the demo: set the
   company default to German.
4. **Every route owner is a person without a mailbox** (10 routes, owners unlicensed). In pilot, their notices bounce at
   Brevo. That adds hard bounces to the Brevo account, which can hurt its reputation.
5. **Go-live cannot pass on a shared-box test stack:** off-box backups and a second factor for generated managers block
   it, and there is no operator override. Every stack on the box has `offbox: false`.
6. **Raise as the desk owner sends no notice:** NextUp does not mail the actor about their own event. That is intended,
   but easy to trip over in a demo: the first tries were made as Julia in another browser and stayed drafts.
