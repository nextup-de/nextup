# Context: market and strategy research

Research done on 2 Nov 2026 for NextUp's positioning towards large DACH automotive companies (OEMs and large Tier-1).
Each report was written from the research notes in [notes/](notes/); links that start with `file:///B:/...` point to
the author's machine and the private plans repo and do not resolve here.

Competitor facts are vendor claims from public pages as of 2 Nov 2026. Statements about NextUp's code refer to
`origin/main` on that day; later reports correct earlier ones, so read them in order.
